# 🤖 Tutor Competenze Digitali - DigComp 2.2

Un'applicazione web interattiva progettata per guidare gli utenti nella valutazione e nel potenziamento delle **competenze digitali**, in linea con il framework europeo **DigComp 2.2**.



## 🎯 Obiettivi del Progetto

Il tutor supporta l'utente nella navigazione delle 5 aree di competenza DigComp:
1. **Alfabetizzazione su dati e informazioni**
2. **Comunicazione e collaborazione**
3. **Creazione di contenuti digitali**
4. **Sicurezza**
5. **Risoluzione di problemi**

## 🚀 Funzionalità

- **Valutazione interattiva**: Quiz e scenari pratici per testare il proprio livello digitale.
- **Interfaccia Web Leggera**: Funziona direttamente nel browser senza configurazioni complesse.
- **Risorse DigComp 2.2**: Contenuti aggiornati basati sulle ultime linee guida europee.

## 🛠️ Tecnologie Utilizzate

- **HTML5**: Struttura semantica dell'applicazione.
- **CSS3**: Stile e design responsive (adatto a PC e smartphone).
- **JavaScript**: Logica interattiva del tutor e calcolo del punteggio.

## 📦 Come Avviare il Progetto in Locale

Essendo un progetto basato su HTML, non richiede installazioni:

1. Clona o scarica questo repository sul tuo computer.
2. Apri la cartella del progetto.
3. Fai doppio clic sul file **`index.html`** per avviarlo direttamente nel tuo browser web.
